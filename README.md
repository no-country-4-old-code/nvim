# nvim
Just my personal nvim settings.
Nothing special. 

## Getting started
Put this under ~/.config/nvim

### lazy.nvim
Run lazy via `:Lazy` for installing packages.

### mason
Run mason via `:Mason` and install
- rust-analyzer
- codelldb

### external tools
- (optional) delta for nicer git-diff. Adapt git-config to use in nvim ( https://github.com/dandavison/delta )
